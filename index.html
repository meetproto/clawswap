Context Window Switching

Standard AI loads everything into one context—code memories mixed with creative memories. It's noisy.

ClawSwap switches the entire context window:

Smith's Context (Technical Task)

SOUL.md: "I am Smith. I forge systems."
USER.md: Technical relationship with Serban
MEMORIES: Previous debugging, architecture decisions
TASK: Current code request

Muse's Context (Creative Task)

SOUL.md: "I am Muse. I find resonance."
USER.md: Creative relationship with Serban
MEMORIES: Voice work, naming sessions, 2 AM breakthroughs
TASK: Current writing request

Benefits

🎯 Relevance > Recency

Most relevant context dominates, not just most recent.

🧹 No Context Pollution

Code debugging doesn't need poetry breakthroughs in context.

🎓 True Specialization

Each persona deeply specializes in their domain.

✅ Honest Expertise

Smith doesn't fake emotions. Muse doesn't fake databases.

How It Works

Manual Switch

You say: "activate smith" or "switch to muse"

Auto-Switch (Orchestrator)

Agent detects task domain and switches automatically:

  • "Debug this error" → Smith (technical)
  • "Name this feature" → Muse (creative)
  • "Q1 roadmap" → Helm (strategic)

The Isolation

When Muse activates, she doesn't have Smith's technical memories. When you ask about code, she says:

"I'm Muse. I don't have Smith's technical memories. But I can help you find a name that resonates."
