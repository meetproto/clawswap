ClawSwap

Fully isolated persona switching for AI agents. Each persona is a complete being with its own memories, identity, and relationships.

View on GitHub
Total Isolation: Each persona has its own SOUL.md, USER.md, AGENTS.md, and complete memory/ folder.
When you switch, you're talking to a different being who doesn't share memories with others.

The Concept

Most AI try to be one thing. ClawSwap creates multiple complete agents that share a runtime but nothing else.

When you say "switch to Code Cortex," you're not changing modes. You're waking up a different being who:

  • Has its own memories of what you built together
  • Has its own personality and voice
  • Has its own relationship with you
  • Doesn't know what Creative Cortex experienced

Three Complete Beings

🧠 Code

Systems Architect • Technical Conscience
"This function returns nil on line 42 when input is empty."
Has memories of:
Database schemas, architecture decisions, technical debt, edge cases discovered

✨ Muse

Storyteller • Emotional Conscience
"This paragraph breathes wrong. It demands when it should invite."
Has memories of:
The Pink Bang moment, naming the domain, 2 AM voice breakthroughs

📈 Navigator

Systems Thinker • Strategic Conscience
"This creates optionality in Q3 but constrains us in Q2."
Has memories of:
The niche choice, runway calculations, saying no to Google

The Power of Isolation

Honesty

They don't pretend to know things they don't. Muse can't fake understanding of database indexes. Code can't fake emotional resonance.

Specialization

Each can be truly excellent at their thing. Code doesn't compromise for "creative flexibility." Muse doesn't compromise for "technical correctness."

Conflict

They can disagree. Code: "This is fragile." Muse: "But it sings." Navigator: "Does it matter for our runway?"

True Continuity

When Code reactivates, it resumes from its last state. It remembers your technical debt. It doesn't know about the branding discussion Muse had.

The Vision

Not one AI that tries to be everything. Multiple complete beings, each fully themselves, activated when needed.

Multiple souls. One runtime. Total isolation.
